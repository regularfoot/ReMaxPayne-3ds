# Работа с исправлениями

- Для каждого найденного бага ищи общий механизм в коде и ресурсах игры. Проверяй другие карты, сцены и режимы, где действует тот же механизм. Исправляй подтверждённую общую причину и проверяй исходное место вместе с похожими случаями. Если причина ограничена одной сценой или данных для общего исправления пока мало, сохраняй узкую область правки и указывай, что удалось проверить.
- Сохраняй сборку, подтверждённую на консоли, для сравнения. Для регрессий, которые не воспроизводятся в эмуляторе, результат на физической 3DS остаётся решающим.
- Сохраняй штатный туман при отрисовке неба кампании. Отдельный проход, который выключал туман и менял текстурное смешивание для неба, возвращал тёмный прямоугольник на статуе Свободы и пропадание объектов на New 3DS. Аппаратная проверка сборки `train-tunnel-sky-fog-rollback` после отката прохода подтвердила стабильность объектов. Остаточное мерцание тона неба рассматривай отдельно.
- Для прозрачных материалов сохраняй проверенный на консоли порядок Alpha Order. Сначала отрисовывай декали, затем остальные прозрачные материалы в порядке отправки. Варианты Light Blend и Sky Color аппаратную проверку не прошли.
